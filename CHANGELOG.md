# Changelog

## [1.3.1] — 2026-11-20

### Исправлено
- `requirements.txt`: добавлены `sv-ttk`, `darkdetect`, `pywinstyles`, `netifaces` —
  без них приложение не запускалось после чистого `pip install -r requirements.txt`.
- Аргументы перезапуска с правами администратора корректно экранируются
  (`subprocess.list2cmdline`), а не склеиваются пробелами.
- Настройки сканирования снимаются в UI-потоке и передаются в рабочий поток —
  больше нет обращений к Tk-переменным из фонового потока.
- Ошибка в фоновом сканировании больше не оставляет кнопки «Сканировать/Стоп»
  заблокированными.
- ISAPI теперь проверяет хосты подсети, даже если выбран единственным методом
  (раньше при пустом списке найденных IP не делал ничего).
- Таблица результатов очищается перед заполнением — нет дублей при повторном обновлении.
- CSV сохраняется в UTF-8 с BOM и стабильным порядком колонок (корректно открывается в Excel).
- `--help` теперь показывает справку, а не запускает GUI.
- Исправлена опечатка в имени автора.

## [1.3.0] — 2026-11-02

- Расширенное обнаружение (ARP/Port/ISAPI), обновлённый GUI и справка по методам сканирования.
